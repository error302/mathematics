# Linear Equations and Equivalence Transformations

## 1. Equivalence-Preserving Operations

An equation is a logical statement that two expressions represent the exact same value. To isolate an unknown variable $x$, we apply **reversible equivalence transformations** to both sides simultaneously:
- Add or subtract the same quantity $C$ on both sides: $L = R \iff L - C = R - C$.
- Multiply or divide both sides by the same non-zero rational number $k \neq 0$: $L = R \iff \frac{L}{k} = \frac{R}{k}$.

## 2. Variables on Both Sides

To solve $ax + b = cx + d$ (where $a \neq c$):
1. Subtract $cx$ from both sides so the variable appears in only one term:
   $$(a - c)x + b = d$$
2. Subtract $b$ from both sides to isolate the variable term:
   $$(a - c)x = d - b$$
3. Divide by $a - c$:
   $$x = \frac{d - b}{a - c}$$

## 3. Distributive Linear Equations Over $\mathbb{Q}$

When parentheses appear, such as $k(ax + b) = cx + d$:
1. Distribute $k$ across **both** terms inside the parentheses:
   $$kax + kb = cx + d$$
2. Collect $x$-terms on the left and constants on the right:
   $$(ka - c)x = d - kb$$
3. Express the exact rational solution in lowest terms:
   $$x = \frac{d - kb}{ka - c} \in \mathbb{Q}$$
