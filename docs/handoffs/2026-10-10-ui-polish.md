# AXIOM UI polish handoff

The project owner requested a UI polish pass after the independent review. The implemented direction is recorded in ADR-0002. All changes are local; existing brand assets and the normative source of truth are preserved. This adds no claim of production or educational readiness.

## Result

- Compact academy header and five short navigation labels: Explore, Lessons, Practice, Abacus, Progress. All remain visible on a 320-pixel viewport. A skip link reaches the main study content; switching screens resets scroll and focuses main content.
- Restrained navy/gold surfaces, local serif headings and system sans reading text. Removed the competing purple accent and gradient reward badges. No new font, image or package downloads are required.
- The curriculum opens with a genuine half/two-quarters illustration and a working place-value lesson entry. Five partial draft courses are shown first; the complete roadmap remains searchable/filterable, with 78 planned courses in compact expandable rows.
- Lesson reading layout separates explanations, worked steps, misconceptions, self-checks and notes. Rendered components now have matching styles. The twelve draft introductory subtitles use beginner-facing language; mathematical activities are unchanged.
- Practice has clear input labels, restrained feedback, simpler action labels and unchanged Rust grading/reward authority. Abacus retains the existing instrument and keyboard controls.
- Progress has real local reward totals and a working empty-state action. Export/restore feedback is inline, bad imports preserve existing data, and captions explicitly say reward exports exclude notes and unfinished answers. Technical reward keys remain accessible in record details.
